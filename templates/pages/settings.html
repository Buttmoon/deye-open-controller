Timezone

Имя приложения, Scheduler и логи

Если оставить пустым, на главной странице будет использоваться имя первого инвертора.
Аварийный режим: времена точек выбираются из ближайших точек расписания текущих суток, но параметры KW/АКБ/Charge Mode берутся из текущего слота расписания. Используй, если инвертор продолжает путать точки.
Интервал указывается в минутах. После сохранения scheduler перезапускается и начинает работать с новым интервалом.

Ручная запись Modbus-регистра

Безопаснее указывать code: адрес, масштаб, модельные пределы и bitmask берутся из JSON-профиля. Известный read-only адрес и raw-запись в bitfield блокируются. Запись выполняется через FC16 с паузой 2 секунды и обязательным read-back. Если IP/Port оставить пустыми, будет использован первый активный инвертор из расписаний.

Если указан code и address пуст, применяется профильная проверка и безопасный read-modify-write для битовых регистров. Если указан address, значение считается raw; для известных профильных адресов всё равно проверяются read-only, диапазоны и запрет обхода bitmask.
Ответ появится здесь после отправки.

Настройка времени инвертора

Адреса трёх слов времени определяются по code из профиля выбранной модели. Запись выполняется через WriteRegisters/FC16 по одному регистру за раз. Если IP/Port пустые — используется первый зарегистрированный инвертор и его профиль.

Ответ появится здесь после записи времени.
